YANG AI v5.3.0 — endi IDE ham SHU o‘rnatuvchining ichida (aicomp.uz)

Yangiliklar (v5.3.0):
- 🖥 **YANG IDE endi ilova ichida** — alohida `.exe` shart emas: yon paneldagi **«YANG IDE»** tugmasi yoki **Fayl → YANG IDE oynasi** (`Ctrl+Shift+I`) bilan to‘liq kod muharriri ochiladi. IDE o‘sha jarayonda, shu o‘rnatuvchi bilan birga keladi (paketga `ide/**` qo‘shildi).
- 🧠 **Bitta sozlamalar, bitta model** — IDE YANG AI bilan bir xil `%APPDATA%/yang-ai` papkasini ishlatadi: API kalitlar, provayderlar va tanlangan model ikkala oynada bir xil. «jamoa» rejimi ham ishlaydi.
- 🐛 **Muhim tuzatish:** ilova ichidagi IDE paneli umuman ishlamasdi — `main.js` mavjud bo‘lmagan `chats` obyektini o‘qib, fayl daraxti va tahrirlash oqimini yiqitardi. Endi ish papkasi haqiqiy manbadan (`loadChat`) olinadi.
- 🐛 **F5 (faylni ishga tushirish) tuzatildi:** JS fayl electron.exe bilan ochilib `exit code 1` berardi — endi `ELECTRON_RUN_AS_NODE` rejimida oddiy Node kabi ishlaydi (PC’da Node o‘rnatilmagan bo‘lsa ham).
- 🐛 **Terminal tuzatildi:** qo‘shtirnoq bilan boshlanadigan buyruq (`"C:\Program Files\app.exe"`) «is not recognized…» berardi — endi `cmd.exe` chaqiruvi Node’ning shell rejimidagidek qo‘llanadi.
- 🐛 **Diagnostika tuzatildi:** JS/JSON sintaksis tekshiruvi «App threw an error during load» degan soxta xato ko‘rsatardi — endi haqiqiy qator raqamli `SyntaxError`.
- ✅ **Sinovlar:** kontrakt testi 7 guruhga kengaydi (`npm run test:ide`, 29 tekshiruv) va haqiqiy ilova ustida CDP orqali E2E sinov qo‘shildi (`ide/test_embedded_e2e.mjs`, 9 tekshiruv — dev va paketlangan nusxada ham o‘tadi).
- 📄 **Hisobot:** IDE nima qila oladi, nima uchun kerak va lokal AI bilan integratsiyasi — `docs/YANG-IDE-hisobot.md`.

IDE ichida nima bor:
- Ko‘p tabli muharrir: qator raqamlari, sintaksis bo‘yash, avtomatik to‘ldirish, qavs juftligi, `Ctrl+/` izoh, topish/almashtirish (`Ctrl+F` / `Ctrl+H`), tez ochish (`Ctrl+P`), ta’rifga o‘tish (`F12`).
- Fayl daraxti, butun loyiha bo‘yicha qidiruv, yangi fayl/papka, qayta nomlash, savatga o‘chirish.
- Terminal (oqim bilan, ANSI ranglar, `cd`), «Muammolar» va «Faoliyat» panellari, fayl kuzatuvchisi.
- AI paneli: model tanlash, vazifa berish, «Xatoni tuzat», «To‘xtatish», jamoa rejimi.
- Xavfsizlik: barcha fayl amallari ochilgan papka ichida qamalgan (`..` va absolyut yo‘l rad etiladi), o‘chirish savatga, `contextIsolation: true`.

Lokal AI bilan integratsiya:
- Ilova ichidagi model (llama.cpp + Qwen3.5-2B, kalit va internet shart emas) — YANG AI allaqachon ko‘targan bo‘lsa qayta yuklanmaydi.
- Ollama (`localhost:11434`) va LM Studio (`localhost:1234`) kalitsiz ulanadi; «Lokal skan» ularni topib, asosiy model qilib qo‘yadi.
- O‘lchov: 4 vazifada `qwen2.5-coder:7b`/`qwen2.5:7b` (Ollama) **4/4**, ilova ichidagi 2B model **3/4** (`reports/local_ai/local-ai-hisobot.md`).

Windows 10/11 x64. Yangilanish ilova ichida o‘zi aniqlanadi.
