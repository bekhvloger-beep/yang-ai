YANG AI v5.4.0 — IDE endi chinakam muharrir: haqiqiy terminal, tip tekshiruvi, debugger va o‘zini tuzatuvchi halqa (aicomp.uz)

Yangiliklar (v5.4.0):
- 🖥 **Haqiqiy terminal (PTY)** — ConPTY + xterm.js: endi `vim`, `top`, `ssh`, `python` REPL kabi **interaktiv** dasturlar ishlaydi (avval faqat quvur rejimi bor edi). Terminal o‘lchami panel bilan birga o‘zgaradi; PTY yuklanmasa IDE eski rejimga jimgina qaytadi.
- 🧠 **Til xizmati (tsserver)** — VS Code ichida ishlaydigan aynan o‘sha dvigatel: yo‘q funksiya, noto‘g‘ri tur, ishlatilmagan o‘zgaruvchi kabi **semantik xatolar** «Muammolar» panelida ko‘rinadi. **F12** haqiqiy ta’rifga o‘tadi (so‘z qidiruvi emas), **Shift+F12** butun loyiha bo‘yicha havolalarni topadi, kursor ostidagi belgi uchun **hover** (tur/imzo) chiqadi. Python uchun `pyflakes` bo‘lsa semantik tekshiruv ham ishlaydi.
- 🐞 **Qadamlab debugger** — qator raqami ustida bosib nuqta qo‘ying (yoki **F9**), «Debug» tugmasini bosing: dastur nuqtada to‘xtaydi, **F10/F11** bilan qadamlab yurasiz, «Debug» panelida chaqiruvlar zanjiri va o‘zgaruvchilar (scope) ko‘rinadi. Node inspector (CDP) orqali, foydalanuvchida Node o‘rnatilmagan bo‘lsa ham.
- 🛠 **«Sinab ko‘r + tuzat»** — bitta tugma: fayl ishga tushadi, xato chiqsa model **muammoli fayl matnini**, **butun tarixni** (buyruq, chiqish kodi, chiqish oxiri, IDE diagnostikasi, oldingi urinishlar) ko‘rib tuzatadi va qayta ishga tushiradi (3 martagacha). «Avval nima qilinganini takrorlamang» — shuning uchun model xatoning ildiziga o‘tadi. Fayl matni darhol beriladi va bitta urinishga **qadam chegarasi** qo‘yilgan: lokal model faylni qidirib yoki bir xil buyruqni takrorlab vaqt yoqib yubormaydi.
- 📜 **Tarix (log) paneli** — har bir yurish saqlanadi: buyruq, chiqish kodi, vaqt, chiqish oxiri. Qatorni bosing — to‘liq chiqish ochiladi. Tarix diskda saqlanadi (ilova qayta ochilsa ham qoladi) va AI kontekstiga kiradi.
- ♾ **Tahrir chegarasi olib tashlandi** — ilgari 2 MB dan katta fayl umuman ochilmasdi. Endi chegara yo‘q: yagona himoya 512 MB (xotira). Katta fayllarda IDE qotmasligi uchun qator raqamlari faqat ko‘rinadigan oyna uchun chiziladi, sintaksis bo‘yash o‘chadi (holat qatorida ogohlantirish).
- ✅ **Sinovlar:** statik kontrakt **44 tekshiruv** (8 guruh), mustaqil oyna sinovi **24 tekshiruv**, haqiqiy ilova ustida CDP E2E **14 tekshiruv** (PTY `isatty`, semantik xato, F12/havolalar/hover, nuqtada to‘xtash + o‘zgaruvchilar, tarix, 3 MB fayl bilan chegarasiz tahrir), va **jonli tuzatish halqasi** sinovi (Ollama + `qwen2.5-coder:7b`).
